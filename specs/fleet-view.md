# Fleet view contract

Show task, selected host, actual native session, browser, trace and artifact identities with observed timestamps and explicit stale/offline/unknown states. Projections never grant execution authority.

Display the actual operated desktop/browser through KasmVNC where supported. Passive observation and control takeover require separate admission. Do not use a simulated view as evidence of real browser integration. Native desktop fallback remains conditional on compatibility qualification.

Public examples use synthetic host identifiers and data only. No real fleet addresses, screenshots, conversations or credentials.
